## Как запустить в IntelliJ IDEA

1. Открой папку проекта и выбери установленный JDK в настройках проекта.
2. Если IDE не распознала `src` как папку с исходниками, щёлкни по ней правой кнопкой и выбери **Mark Directory as → Sources Root**.
3. Открой нужный класс из таблицы и нажми зелёный треугольник рядом с методом `main`. Если программа ждёт ввода, введи данные в консоли **Run**.
4. Для `Num15` перед запуском укажи, например, `один два три` в поле **Program arguments** конфигурации запуска. Это аргументы запуска, а не ввод в консоли.
